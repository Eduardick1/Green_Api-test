# Telegram-чат через GREEN-API

## Запуск

```sh
npm install
npm run dev
```

## Подключение

1. Создайте Telegram-инстанс GREEN-API и авторизуйте Telegram-аккаунт в [личном кабинете](https://console.green-api.com/).
2. В настройках инстанса включите `incomingWebhook: "yes"` и оставьте `webhookUrl` пустым для [получения через HTTP API](https://green-api.com/telegram/docs/api/receiving/technology-http-api/).
3. Введите `idInstance` и `apiTokenInstance` в приложении.
4. Создайте чат по международному номеру телефона, отправьте текст и ответьте из Telegram получателя. Если [CheckAccount](https://green-api.com/telegram/docs/api/service/CheckAccount/) не находит номер, он может быть скрыт настройками приватности.

Учётные данные хранятся только в памяти; после перезагрузки их нужно ввести снова. История сохраняется под ключом `telegram-chat:v1:<idInstance>` в `localStorage` того же браузера и адреса сайта. Предполагается одна активная вкладка на инстанс. Выход сохраняет историю, но очищает подключение и credentials.

Статус «Принято» означает принятие сообщения в очередь GREEN-API, а не подтверждение доставки. При таймауте результат отправки может оставаться неизвестным; приложение не повторяет отправку автоматически. Входящие сохраняются до подтверждения уведомления, а повторные уведомления не создают дубликаты.

При ошибке сохранения получение приостанавливается, а несохранённое входящее уведомление остаётся в очереди. После устранения проблемы хранилища отключитесь и подключитесь заново.
